Tool bridge: when may the surface end the turn?

A client defines a tool on the Anthropic surface. Upstream (the Claude Code run) decides to call it. The surface must hand the call to the client as stop_reason: tool_use while the run stays alive, blocked inside the wrapper's MCP tool handler, and must feed the client's answer back on the next turn. This page lets you drive that state machine by hand. The logic is the same module the live spike ran against the real CLI; the buttons are the events the spike saw.
